# 🐰 Talking Rabbitt – Conversational Data Analytics

Talking Rabbitt is a conversational AI analytics prototype that allows users to interact with business data using natural language. Instead of manually filtering dashboards or spreadsheets, users can simply ask questions about their data and instantly receive insights and visualizations.

This project demonstrates the **"Magic Moment"** where a 10-minute manual Excel analysis is replaced with a **5-second AI conversation**.

---

# 🚀 Features

• Upload a CSV dataset  
• Ask questions about your business data  
• AI-powered natural language responses  
• Automatic data visualization  
• Interactive charts for quick insights  

Example question:

Which region generated the highest revenue in Q1?

The system returns:

• A clear AI answer  
• A visualization of revenue by region

# 🎯 Project Goal

The objective of this prototype is to demonstrate how conversational AI can simplify enterprise analytics by allowing decision-makers to interact with business data through natural language queries.

Talking Rabbitt enables:

• Faster decision making  
• Improved data accessibility  
• Reduced reliance on manual data analysis
